# Support

- **Something is broken?** Run `node scripts/doctor.mjs --profile desktop`
  first, then open a [bug report](https://github.com/elliotmasheal/dsh-provider-enhance/issues/new?template=bug_report.yml)
  with its output.
- **Installation or upgrade question?** Read the README
  ([English](README.md) · [中文](README.zh.md)) and
  [docs/upgrading.md](docs/upgrading.md).
- **Feature request?** Open a
  [feature request](https://github.com/elliotmasheal/dsh-provider-enhance/issues/new?template=feature_request.yml).
- **Security issue?** Follow [SECURITY.md](SECURITY.md); do not open a public
  issue.
- **Problem with DeepSeek Harness itself?** Report it to the
  [DeepSeek Harness project](https://github.com/deepseek-ai/deepseek-harness).

This is a small, volunteer-maintained project; there is no guaranteed response
time, but bug reports that include the doctor output and a minimal reproduction
are answered first.
